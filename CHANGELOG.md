# Changelog

All notable changes to this repository will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-15

### Added
- Initial repository structure
- Comprehensive README.md with phenomenon documentation
- api.json following Wyrdness schema v1.0.0
- SOURCES.md bibliography
- Issue templates for sighting reports, corrections, and source additions
- Pull request template

### Data Included
- Basic phenomenon metadata and classification
- Physical characteristics and abilities
- Geographic distribution and hotspots
- Historical timeline (1811-present)
- 3 notable sightings (Patterson-Gimlin, Ape Canyon, Ostman)
- Evidence catalog (physical, photographic, audio)
- Theories (cryptozoological, skeptical)
- Cultural significance and Indigenous perspectives
- Research organizations and notable researchers
